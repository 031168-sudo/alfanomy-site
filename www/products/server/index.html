Телематический сервер

- Сбор, хранение и обработка данных, полученных от навигационного оборудования и других телематических серверов и систем.

- Передача данных в автоматизированные рабочие места, Web-приложения, Мобильные приложения, серверы и системы.

- База данных для хранения данных пользователей, сигналов, информации внесенной диспетчерами, инженерами, менеджерами, администраторами.

Сервер

- обработка нескольких десятков сообщений в секунду;

- работа по СМС через модем и SMPP протокол с серверами операторов;

- рабта по GPRS через интернет соединение;

- интерфейс администратора для настройки и управления;

- автоматизированные рабочие места: диспетчера, инженера, менеджера;

- система биллинга;

- модуль генерации отчетов;

- WEB-приложения;

- мобильные приложения;

- интеграция протоколов для работы с любыми телематическими блоками;


Применение

  1. Мониторинг и охрана автотранспорта и любых подвижных объектов.
  2. Персональный мониторинг.
  3. Охрана ценных грузов.
  4. Охрана недвижимости.
  5. SMPP сервер для работы с СМС (прием и передача).
