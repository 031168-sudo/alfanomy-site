# Сайт Alfanomy

Статическая копия сайта Alfanomy (исходно сделан на Jimdo, alfanomy.jimdo.com).
Всё, что выкладывается на сервер, лежит в папке `www/`.

## Что изменено относительно исходной копии

- Кнопки **App Store** и **Android** на страницах «Главная», «Готовое решение для
  бизнеса», «Подключение телематических модулей» и ENG ведут на новое приложение:
  - App Store: https://apps.apple.com/ru/app/id6814783331
  - RuStore: https://www.rustore.ru/catalog/app/ru.alfanomy.mapp
- Значки «Get it on Google Play» заменены на «Download for Android».
- Название AlfaSputnik заменено на Alfanomy во всех текстах и заголовках страниц
  (адреса страниц не менялись).
- Страница ENG переписана под приложение Alfanomy, галерея — новые скриншоты.
- Картинки «Клиентские приложения», схемы с подписью «(c) Alfanomy» и телефоны
  с экранами нового приложения — в `www/image.jimcdn.com/alfanomy-app/`.

## Как выложить на сервер

1. Сделать резервную копию папки сайта на сервере (например, `www_backup`).
2. Скопировать содержимое папки `www/` из репозитория поверх папки сайта,
   соглашаясь на замену файлов.
3. Открыть сайт и нажать Ctrl+F5.

Откат: удалить папку сайта и переименовать резервную копию обратно.
